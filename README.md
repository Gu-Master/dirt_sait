# Бро из грязи

Локальная галерея-органайзер для серии фото "Бро из грязи".

## Что умеет

- просмотр в режиме портала, ленты и сетки;
- добавление фото из файлов, папки, drag-and-drop и буфера;
- избранное, поиск, сортировка и переименование;
- удаление фото и поиск точных дублей;
- хранение добавленных фото в IndexedDB браузера.

## GitHub Pages

Сайт статический: GitHub Pages можно включить для ветки `main` и папки `/root`.

Локальный запуск:

```powershell
node server.js
```

После запуска сайт доступен на `http://127.0.0.1:5177`.
